# Topics

This directory stores active topic plans that are still in progress.

## Active Plan Location

- The canonical path for an active topic plan is `docs/topics/<topic-name>/plan.md`.
- Keep the approved `plan.md` here while any milestone for that topic is still incomplete.
- Move the plan to `docs/archive/<topic-name>/plan.md` only after all milestones for that topic are complete.

## Example

- `docs/topics/search-autocomplete/plan.md`
